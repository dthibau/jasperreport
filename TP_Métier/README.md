# Ateliers – Formation JasperStudio pour utilisateurs métier (2 jours)

Dix ateliers alignés sur le support `JasperStudioMetier.pptx`. Tous utilisent la base d'exemple livrée avec Jaspersoft Studio (data adapter **Sample DB**) : aucune installation de base de données.

| Atelier | Dossier | Thème | Point de départ |
|---|---|---|---|
| 1 | `1_Interface` | Découverte de l'interface, Outline, Properties, onglets Design / Source / Preview (guidé clic par clic) | – |
| 2 | `2_BaseExemple` | Base d'exemple, data adapter JDBC, assistant de requête | – |
| 3 | `3_DeuxColonnes` | Dimensions, bandes, liste sur deux colonnes | atelier 2 |
| 4 | `4_Parametres` | Paramètres de requête | – |
| 5 | `5_ElementsSimples` | Éléments simples, mise en forme de type tableau | – |
| 6 | `6_Images` | Logo, filigrane, livraison des images | atelier 4 |
| 7 | `7_Police` | Police spécifique (Gentium), extension de police | atelier 3 |
| 8 | `8_Charte` | Styles, styles conditionnels, bibliothèque `.jrtx` | atelier 5 |
| 9 | `9_Pagination` | Page de garde, contrôle de la pagination | – |
| 10 | `10_Expressions` | Expressions : concaténation, conditions, dates | – |

Chaque dossier contient :

- l'énoncé `AtelierN_*.pdf` (et `.odt` modifiable, `.md` source) ;
- le résultat attendu `AtelierN_ResultatAttendu.pdf`, à ouvrir avant de commencer ;
- les ressources nécessaires (images, polices) à copier dans le projet Studio.

Les rapports `.jrxml` corrigés ne sont pas fournis aux stagiaires : ils sont dans le projet Studio `TP_Métier_Solutions/SolutionsAteliers` (formateur).

Prérequis poste stagiaire : Jaspersoft Studio Community 7.0.8, un workspace vide, les dossiers d'ateliers copiés localement.
